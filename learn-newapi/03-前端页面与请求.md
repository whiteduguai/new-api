# 03 前端页面与请求

## 一句话概括

前端是 **React 19 + TanStack Router（文件路由）+ TanStack Query（请求缓存）+ Zustand（全局状态）+ Tailwind**。

页面文件都在 `web/src/routes/`，业务组件都在 `web/src/features/`。

## 目录结构

```
web/src/
├── routes/         页面路由（文件即路由，自动生成 routeTree.gen.ts）
├── features/       业务功能模块（页面主体、接口、类型、组件）
├── components/     通用组件（ui/ 是基础控件，其余是业务封装）
├── lib/            工具与请求封装（http-client、api、auth-session…）
├── hooks/          通用 hooks
├── stores/          Zustand 全局状态
├── context/        React Context Provider
├── i18n/           多语言
└── styles/         全局样式
```

## 第 1 站：routes —— 文件即路由

TanStack Router 使用**文件路由**：`web/src/routes/` 下的文件路径就是 URL。

例子：

| 文件 | URL |
| --- | --- |
| `routes/index.tsx` | `/` |
| `routes/pricing/index.tsx` | `/pricing` |
| `routes/_authenticated/channels/index.tsx` | `/channels` |
| `routes/_authenticated/dashboard/$section.tsx` | `/dashboard/:section` |
| `routes/_authenticated/system-settings/billing/index.tsx` | `/system-settings/billing` |

约定：

- `_authenticated/` 是**布局路由前缀**，表示这组页面需要登录，本身不出现在 URL 里
- `$section` 是动态参数，组件里用 `Route.useParams()` 取
- `(auth)`、`(errors)` 是**分组**，只影响文件组织，不影响 URL

一个典型路由文件 [routes/_authenticated/channels/index.tsx](../web/src/routes/_authenticated/channels/index.tsx)：

```tsx
export const Route = createFileRoute('/_authenticated/channels/')({
  beforeLoad: () => {
    const { auth } = useAuthStore.getState()
    if (!auth.user || auth.user.role < ROLE.ADMIN) {
      throw redirect({ to: '/403' })
    }
  },
  validateSearch: channelsSearchSchema,   // 校验 URL 查询参数
  component: Channels,                    // 真正的页面在 features 里
})
```

要点：

1. 路由文件只做三件事：路径定义、权限守卫、把 `component` 指向 feature
2. `routeTree.gen.ts` 是自动生成的，**不要手改**
3. 新增路由文件后，Rsbuild 的 TanStack Router 插件会自动重新生成路由树

## 第 2 站：features —— 真正的页面

以礼品码为例：

```
web/src/features/redemption-codes/
├── index.tsx              页面主体
├── api.ts                 这个模块的所有接口调用
├── types.ts               请求/响应类型
├── constants.ts           枚举、默认值、i18n key
├── lib/                   纯函数与校验
└── components/            这个模块专用的组件
```

推荐阅读顺序：

1. `index.tsx`：页面布局，看它用了哪些组件
2. `api.ts`：这个页面会调哪些后端接口
3. `types.ts`：接口返回的数据长什么样
4. `components/`：表格、弹窗等细节

## 第 3 站：请求层（前后端"握手"的地方）

### 统一 axios 实例

[web/src/lib/http-client.ts](../web/src/lib/http-client.ts)：

```ts
export const api = axios.create({
  baseURL: '',            // 关键：空字符串 = 当前源
  withCredentials: true,  // 关键：自动带 Cookie
  headers: { 'Cache-Control': 'no-cache, no-store' },
})
```

`baseURL: ''` 意味着：

- 开发时请求发到 `http://localhost:5173/api/...`，由 Rsbuild 代理到 3001
- 生产时请求发到 `http://localhost:3001/api/...`，由 Go 直接处理

所以**前端代码里永远只写 `/api/...`，不要写完整域名**。

### 请求拦截器：自动加登录凭证

[web/src/lib/http-client.ts](../web/src/lib/http-client.ts) 第 146-165 行：

```ts
api.interceptors.request.use(async (config) => {
  const accessToken = useAuthStore.getState().auth.accessToken
  if (accessToken) {
    config.headers.Authorization = `Bearer ${accessToken}`
  }
  return config
})
```

### 响应拦截器：401 自动刷新

第 86 行起：遇到 401 会尝试 `refreshAuthentication()`，刷新成功后自动重放原请求；刷新失败才跳登录页。

新手不要自己再包一层 axios，也不要手动拼 Token。

### 通用接口汇总

[web/src/lib/api.ts](../web/src/lib/api.ts) 放跨模块通用接口，比如：

```ts
export async function getSelf() {
  const res = await api.get('/api/user/self', { skipErrorHandler: true })
  return res.data
}
```

### 模块接口文件

每个 feature 自己维护 `api.ts`。例子 [web/src/features/redemption-codes/api.ts](../web/src/features/redemption-codes/api.ts)：

```ts
export async function getRedemptions(params = {}) {
  const { p = 1, page_size = 10 } = params
  const res = await api.get(`/api/redemption/?p=${p}&page_size=${page_size}`)
  return res.data
}

export async function createRedemption(data) {
  const res = await api.post('/api/redemption/', data)
  return res.data
}
```

## 第 4 站：组件里怎么用

数据获取用 `useQuery`，变更用 `useMutation`，统一来自 `@tanstack/react-query`：

```tsx
const { data, isLoading } = useQuery({
  queryKey: ['redemptions', page],
  queryFn: () => getRedemptions({ p: page }),
})
```

新增/删除后刷新列表：

```tsx
const queryClient = useQueryClient()

const mutation = useMutation({
  mutationFn: createRedemption,
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: ['redemptions'] })
  },
})
```

约定：

- `queryKey` 用数组，带业务名和参数
- 变更成功后 `invalidateQueries` 让列表重新拉取
- 普通请求错误由全局 `handleServerError` 提示，不要每个组件重复弹 Toast

## 第 5 站：全局状态

用 Zustand，store 在 `web/src/stores/`。

```ts
const user = useAuthStore((s) => s.auth.user)   // 只订阅需要的字段
```

规则：优先用选择器，避免整个 store 订阅导致重渲染。

## 第 6 站：国际化

- 所有用户可见文案必须走 `t()`
- 语言文件：`web/src/i18n/locales/{en,zh,zh-TW,fr,ru,ja,vi}.json`
- 新增文案要在**七个语言文件**里都加

```tsx
const { t } = useTranslation()
return <Button>{t('Save')}</Button>
```

## 第 7 站：样式与组件

- 样式优先 Tailwind 工具类
- 基础控件在 `web/src/components/ui/`
- 通用业务封装优先复用：`ConfirmDialog`、`CopyButton`、`DataTable`、`EmptyState` 等
- 新写 UI 前先检索 `web/src/components/` 和对应 feature，不要重复造轮子
